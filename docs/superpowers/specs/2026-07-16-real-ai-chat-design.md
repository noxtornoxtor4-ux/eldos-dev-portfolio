# Настоящий AI в E/D Assistant

Дата: 2026-07-16

## Цель

Заменить подготовленные ответы E/D Assistant на ответы настоящей нейросети.

## Поведение

- Пользователь пишет сообщение и получает обычный содержательный ответ нейросети в чате.
- В ответе пользователю не упоминаются Telegram, пересылка сообщения Эльдосу или ожидание ответа.
- Эльдос незаметно получает в Telegram имя, email, телефон, вопрос пользователя и точный ответ нейросети.
- Вопрос и ответ сохраняются в истории аккаунта и доступны после повторного входа.

## Серверная логика

- Браузер отправляет сообщение существующему защищённому маршруту `/api/chat`.
- Сервер проверяет аккаунт через Supabase и загружает последние сообщения этого пользователя.
- Сервер отправляет контекст диалога в OpenAI Responses API и получает текст ответа.
- Для первого релиза используется `gpt-5.4-mini` как модель с хорошим балансом качества, скорости и стоимости.
- Сервер сохраняет вопрос и полученный ответ в Supabase, затем отправляет их Эльдосу через Telegram Bot API.
- Браузер получает только готовый текст ответа.

## Безопасность и ошибки

- `OPENAI_API_KEY` хранится только в серверных переменных окружения Sites.
- Ключ OpenAI, ключ Telegram, токены Supabase и пароли никогда не отправляются в браузер, Telegram или базу сообщений.
- При недоступности OpenAI пользователь получает короткую ошибку без технических деталей и может повторить отправку.
- Сообщения других аккаунтов никогда не используются как контекст.

## Проверка

- Тест подтверждает, что сервер вызывает OpenAI с вопросом и историей только проверенного пользователя.
- Тест подтверждает, что точный ответ OpenAI сохраняется вместе с вопросом.
- Тест подтверждает, что Telegram получает вопрос и тот же ответ, а пользовательский ответ не содержит упоминаний Telegram.
- Production-проверка выполняется временным аккаунтом с последующим удалением аккаунта и тестовых данных.

## Вне текущего изменения

- Голосовые сообщения, изображения, поиск в интернете и инструменты AI не добавляются.
- Внешний вид чата и существующая система аккаунтов не изменяются.
